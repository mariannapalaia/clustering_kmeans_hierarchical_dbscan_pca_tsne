## Overview
This project explores customer segmentation using clustering techniques on the Wholesale Customers Dataset. The goal is to identify meaningful customer groups based on their annual spending across different product categories.

Dataset: Wholesale Customers Data (Kaggle)

## Techniques Used:

K-Means, HCA, PCA, T-SNE, DBSCAN

## Files
`project_clustering_v2.ipynb`: Full notebook with code, visuals, and explanations.

`Wholesale customers data.csv`: Dataset used in the project.

## Outcome
The analysis successfully identified distinct customer segments and provided insights that can support marketing strategies.
